# Meister 1.1.1 — Mail preview patch

This release provides a patch and local installer for the Meister 6.34 CLI mail preview. Terminal progress updates stay on one line, and elapsed time remains visible during Mail and model requests. Preview pages pool sparse model candidates across up to 100 messages while native reads remain limited to 25.

The installer checks patch compatibility, JavaScript syntax, CLI help and nine regression tests before installation. It uses the CLI's Mail lock, backs up replaced files with SHA-256 hashes, and restores originals if installation fails.

From the extracted release source, run:

```sh
node scripts/install-mail-preview-fix.mjs --check
node scripts/install-mail-preview-fix.mjs
```

The patch requires the compatible Meister 6.34 Homebrew CLI. It takes effect on the next CLI invocation; a Homebrew upgrade may replace it. Installation does not start a Mail job. This release does not update the Homebrew formula or provide a new native app binary.

Validation: all nine mail preview tests and all twelve repository script regression tests passed. The simulated sparse-candidate benchmark uses two model process launches instead of four, with identical decisions; actual model latency was not measured.

## Recap

Mail preview patch and installer published as source. The local CLI installation is patched and verified. No TestFlight release is included.
