# Meister app v1.1.5 — iPhone Duo screen metrics

The iOS hardware view reads the window scene's screen and the view's display
scale. It no longer uses `UIScreen.main`. A hidden probe republishes points
and scale only when they change, including after a display-scale trait change.
Until a window scene exists, resolution, points, and scale show an em dash.

Also on `main` since v1.1.4: Meister CLI roadmap notes. Those notes do not
change the app. The CLI formula stays in `maf4711/homebrew-meister`. ASC client
and test files only changed wrapping; build-number selection is unchanged.

This is a source release of commits already on `main`. It contains no signed
app, App Store publication, or TestFlight upload.
