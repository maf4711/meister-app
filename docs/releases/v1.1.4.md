# Meister app v1.1.4 — faster macOS file scanning

Duplicate scanning streams file discovery and rejects large, same-size files
with different 64 KiB prefixes before reading their full contents. Every
reported duplicate still receives full SHA-256 verification. Hashing reuses
bounded buffers, with at most four workers and cancellation checks in both
stages.

Synthetic scans were 16.4× faster for distinct prefixes and 3.3× faster for a
mixed duplicate set. An instrumented eight-file check read 96.9% fewer bytes.
When all prefixes match, benchmarks show 3–4% extra runtime. These are cached
synthetic measurements, not whole-app or cold-disk performance claims.

Spotlight scanning avoids unused attribute aggregation and result-array
copying. Age filtering now excludes files with either recent use or recent
modification. Completed or failed queries stop cleanly, and stale query
notifications are ignored.

Validation: 32 Python/native-helper tests and 16 Swift package tests passed,
plus iOS helper type checking. Coverage includes sample-size boundaries,
identical prefixes with differing tails, full digest identity, reduced reads,
age filtering, symlinks, overlapping roots, and cancellation during both hash
stages.

This is a source release. It contains no signed app or TestFlight upload.
Full app builds and live Spotlight-index benchmarks were not performed.
