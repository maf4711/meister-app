# Meister app v1.1.3 — faster matching and reliable release checks

Contact deduplication prepares names once and skips pairs that cannot reach the
existing similarity threshold. Four synthetic matching benchmarks improved by
25–881× while preserving group membership.

Photo grouping caches complete-link distances and candidate neighbors, retaining
the original deterministic tie behavior. Four synthetic grouping benchmarks
improved by 1.2–43.7×; the distance-array payload for 500 photos decreases from
1,000,000 to 499,000 bytes. Nonfinite distances no longer imply duplicate photos,
and capture-time groups cannot chain beyond their full 60-second window.

A review of 26 local logs and all 15 available CI logs led to earlier signing
checks, bounded ASC requests, correct numeric build selection across pages,
strict signature verification, and propagation of failed group assignments.
CI now uses checkout's Node 24 runtime and type-checks the iOS engine helpers.

Validation: 30 Python/native-helper tests, 16 Swift package tests, iOS helper
type checking, and shell syntax checks passed on the isolated release source
set. Photo tests include 1,257 generated matrices and explicit safety cases.
Benchmarks measure matching/grouping only, not whole-app performance.

This is a source release. It does not include a signed app, App Store publication,
or TestFlight upload. Full app builds and live signing/upload validation were
not performed. One historical failed CI run's raw logs have expired; retained
annotations were reviewed instead.
